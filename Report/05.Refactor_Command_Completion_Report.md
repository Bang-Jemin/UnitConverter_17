| 신규 메서드 | ≤1 | 0 | ✅ |

### 8.3 구현 변경

**Before (RS-03 이전):**

```python
value = float(value_str.split(":", 1)[0])
```

**After:**

```python
value_token, _, _ = value_str.partition(":")
value = float(value_token)
```

값 구간에서 첫 `:` 앞 숫자 토큰만 취하는 의도를 명확히 함. `meter:2.5:extra` → `2.5` 동작 유지.
