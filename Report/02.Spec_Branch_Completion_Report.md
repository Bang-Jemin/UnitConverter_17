## 3. 아키텍처 골격 (OCP / SRP)

```
unit_converter/
├── domain/
│   ├── length_unit.py      # 단위 개념 · meter 기준
│   ├── unit_registry.py    # 등록·조회 (OCP)
│   └── converter.py        # 변환 계산
├── infrastructure/
│   └── config_loader.py    # JSON/YAML
├── app/
│   ├── input_parser.py     # unit:value
│   └── output_formatter.py # json/csv/table
└── cli.py

tests/
├── test_converter.py       # Track B — Domain / Logic
└── test_cli.py             # Track A — Boundary / UI
```

- **금지 패턴**(레거시 참고): `UnitConverter.py` 16~24행 `if/elif`, 19·21·27·28행 비율 중복
- **데이터 흐름**: `config_loader` → Registry ← Converter ← app/cli
