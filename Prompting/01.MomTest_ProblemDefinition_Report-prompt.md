**실습 1/5 — 새 단위 추가 시 수정 범위**

현재 코드: 입력 `elif`(16–24행), 출력 계산(26–28행), `print` 3줄(30–32행) 분리. README: "새 단위 추가 시 변경 최소화".

**질문 1**

`yard`를 지원 단위에 넣을 때(또는 비슷한 `if/elif` 변환 코드를 확장할 때), **처음 수정한 뒤 실행해 보니 빠뜨려서 다시 고친 곳**이 있었나요? 있다면 **어느 줄/어느 역할**(입력 분기, meter 환산, 출력 계산, `print` 등), **몇 군데**를 손댔는지. 없으면 "없음".
