### 4. 구현 작성

**`input_parser.py`**
```python
def parse(raw: str) -> tuple[str, float]:
    unit, value_str = raw.split(":", 1)
    value = float(value_str)
    return (unit, value)
```

**`unit_registry.py`**
- `RATIO_FEET_PER_METER = 3.28084`, `RATIO_YARD_PER_METER = 1.09361` 단일 정의
- meter/feet/yard를 meter 기준 `meters_per_unit`로 등록

**`converter.py`**
- meter 환산 → Registry 조회 → 전 단위 dict (단위별 `if/elif` 없음)

**`cli.py`**
- `HandleInputResult` dataclass
- format / number / negative 오류 구분
- 정상 시 `convert_all` → `output_lines`
