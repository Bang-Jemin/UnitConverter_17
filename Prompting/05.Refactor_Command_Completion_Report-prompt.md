## Part A — `/refactor-smell` Command 생성

**User**

UnitConverter 프로젝트에 refactor-smell Command를 생성해줘.

생성할 파일:
`.cursor/commands/refactor-smell.md`

목적:
REFACTOR 단계에서 코드를 수정하기 전에,
현재 구현의 코드 스멜을 분석하고 /refactor-safe에 넘길 후보를 제안한다.
이 Command는 분석 전용이며 코드 수정과 커밋을 금지한다.

refactor-smell.md에는 아래 내용을 UnitConverter 프로젝트에 맞게 작성해줘.

(요청 본문 요약)
- Phase: refactor, Scope: unit_converter/ tests/, Track: Logic+UI
- 전제: `python -m pytest tests/ -v` PASS, Golden Master 존재 시 추가 실행
- 스멜 8종 표: Long Method, Duplicated Code, Mysterious Name, Magic Number, 계층 위반, Feature Envy, OCP/SRP 위반
- UnitConverter 계층 기준: domain / app / infrastructure / cli.py
- Change Budget: 수정 파일 ≤3, 신규 클래스 ≤1, 신규 메서드 ≤3, 동작·테스트·approved 변경 금지
- 출력: 스멜 표 → /refactor-safe 후보 1~3개 → P0 1개 선택 안내
- 금지: 코드·테스트·docs·commit·refactor-safe 실행

주의:
- 지금은 Command 파일만 생성한다.
- 실제 리팩토링은 하지 마.
- 코드 스캔도 지금 실행하지 마.

## Part B — `/refactor-safe` Command 생성

**User**

UnitConverter 프로젝트에 refactor-safe Command를 생성해줘.

생성할 파일:
`.cursor/commands/refactor-safe.md`

목적:
refactor-smell 결과에서 선택한 스멜 1개만 안전하게 리팩토링한다.
외부 동작, 테스트 기대값, Golden Master 출력 계약을 변경하지 않는다.
한 번에 하나의 리팩토링만 수행하고, Change Budget 안에서 작업한다.

(요청 본문 요약)
- Phase: refactor, Mode: Agent, Scope: unit_converter/ tests/
- 사용 시점: GREEN PASS, Golden Master matched, refactoring 브랜치, smell 결과 + 후보 1건 선택
- 입력: PRD, TRACEABILITY, TEST_LOOP, .cursorrules, tests, golden, unit_converter, /refactor-smell 결과
- 전제: `python -m pytest tests/ -v` (+ Golden Master)
- Change Budget, 허용/금지 범위, 사후 검증, 롤백 조건

---

**Cursor**

`refactor-smell.md`와 `green-minimal.md` 대칭 구조로 `refactor-safe.md` 작성.

**작업:** `.cursor/commands/refactor-safe.md` **신규 작성** (258 lines)

**핵심 계약:**

| 항목 | smell | safe |
|------|-------|------|
| 역할 | 분석·후보 제안 | 선택 1건 구현 |
| Scope | 읽기만 | `unit_converter/` 수정 |
| 입력 | 선택적 컨텍스트 | **후보 1건 필수** |
| Golden Master | FAIL 시 중단 | FAIL 시 롤백, UPDATE_GOLDEN 금지 |
| 다건 적용 | 후보만 제안 | **2건 이상 금지** |

**리팩터 유형별 가이드:** SRP, OCP, Magic Number, Duplicated Code, Feature Envy, Long Method, Mysterious Name, 계층 위반 — 허용/금지 표 내장

**미변경 확인:** 구현 코드, pytest, tests 기대값, approved — 미수정

**사용 예:**

```
/refactor-smell
→ RS-01 선택
/refactor-safe RS-01
→ PASS 후 /refactor-smell 재실행
```
